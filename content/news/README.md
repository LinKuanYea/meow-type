# 每日新聞（喵打冒險模式「📰 每日新聞」）

每天 **3 篇**：各是一則**國際新聞**，用**自己的話改寫**成高中程度的英文短文，學生打字、學單字、答理解題。學生打完任一篇就算完成當天的任務（連續天數照算），多打的也有小魚乾，每篇各有排行榜。
檔案：`content/news/YYYY-MM-DD-1.json`、`-2.json`、`-3.json`（日期＝台灣時間的當天）。最早的 `2026-11-27.json` 是改版前的長篇（沒有編號），保留不動。寫好後執行 `node scripts/build-text-bank.mjs`（會檢查格式並產生 `shared/news/`），再 `npm test`，全部通過才推到 `main`。推上去就自動上線（林老師決定不用核准；有問題他會在管理頁「每日新聞」下架）。

## 選題
- 過去 1～3 天的國際新聞，值得高中生知道：科學、太空、科技、環境、健康、運動、文化、教育、國際合作。
- 避開：血腥或暴力細節（戰爭、犯罪、災難的傷亡描寫）、自殺、性、名人八卦；立場強烈的政治爭議（選舉輸贏、政黨攻防）。重大國際事件可以寫，但只寫事實、語氣中立、不寫傷亡細節。
- **同一天的 3 篇主題要不一樣**（`topic` 不能重複，檢查會擋），最好一篇偏科學或科技、一篇偏環境或健康、一篇偏運動、文化或國際合作；也跟前幾天的主題錯開（看 `content/news/` 最近幾篇的 `topic`）。
- 3 篇是 3 則不同的新聞，不要把同一則新聞拆成 3 篇。
- 至少找兩個可靠來源互相對照（通訊社、主要媒體、官方機構、期刊或大學新聞稿），數字和人名要對得上。

## 改寫（著作權）
- **不能複製新聞原文**，連改幾個字也不行：只取事實，自己重新組織、重新寫。不要引用原文句子（引號裡的話也改成轉述）。
- 文章結尾不用寫「根據某某報導」，來源放在 `sources`。

## 英文程度
- 每篇 80～120 字（檢查範圍 70～140），1～2 段（最多 3 段）。短篇就好：學生一篇大約 1～3 分鐘打完。
- 高中程度：句子以 10～20 字為主，少用艱深的子句；專有名詞第一次出現時用簡單的話解釋（例如 "A quasar is ..."）。
- 只能用半形字元：英文字母、數字、空白和 `. , ; : ! ? ' " ( ) -`。**不能有彎引號（’ “ ”）、破折號（— –）、全形符號、% 以外的特殊符號**（% 也不行，寫成 percent）。
- 數字照一般寫法（630 million、13.8 billion）。

## 欄位
```json
{
  "date": "2026-11-28",
  "title": "中文標題（60 字以內）",
  "topic": "主題（例：太空科學、環境、科技、健康、運動、文化）",
  "paras": ["第一段英文", "第二段英文"],
  "vocab": [{ "w": "單字或片語（文章裡要找得到）", "pos": "n.", "zh": "中文意思", "lv": 2 }],
  "questions": [{ "q": "英文問題", "options": ["正確答案", "錯誤", "錯誤", "錯誤"], "answer": 0, "why": "中文說明：在第幾段、為什麼" }],
  "sources": [{ "name": "來源名稱", "url": "https://..." }]
}
```
- `vocab`：3～8 個（舊的長篇 5～12 個），挑文章裡高中生值得學的字；`lv`：1 國中、2 高中、3 進階（超出高中範圍）。`pos` 用 n. v. adj. adv. prep. conj. ph.（片語）等。
- `questions`：2～3 題，理解題（不是考單字），答案要能在文章裡找到；正確答案的位置要分散（不要每題都是 0）；選項長度差不多。
- `sources`：1～3 個 https 連結，給想讀原文的學生。
